# Raw data (CCEE BIOMASSA_ACL)

Place here, **unmodified**, every CSV file of the dataset BIOMASSA_ACL downloaded from
https://dadosabertos.ccee.org.br/dataset/biomassa_acl (one file per year is typical).

CCEE blocks automated downloads, so the files were obtained manually through a web browser.
The data are published by CCEE under the Creative Commons Attribution 4.0 licence and are
redistributed here, with attribution, only to make the derived series reproducible.
The SHA-256 hash of each file is recorded in `data/derived/COVERAGE.md`.
